# Luma Arabia

Premium Arabic RTL Photography WordPress Theme — Design & Product Specification

Act as a Senior UI/UX Designer, WordPress Theme Product Designer, and ThemeForest-level design architect.

I want you to design a premium, commercial Arabic-first WordPress photography theme that can later be converted into a real WordPress theme and sold on:

ThemeForest / Envato Market

Directly to photography clients

As a reusable premium WordPress theme

This is NOT a simple photographer landing page.

The design must feel like a complete commercial WordPress theme product, comparable in quality, polish, flexibility, and feature coverage to premium photography themes currently sold on ThemeForest.

1. Core Theme Concept

Create a sophisticated photography portfolio theme for:

Professional photographers

Wedding photographers

Portrait photographers

Fashion photographers

Product photographers

Commercial photographers

Studio photographers

Videographers / filmmakers

The primary design language must be:

Luxury + Editorial + Minimal + Visual + Premium

Photography must always be the visual hero.

Avoid generic corporate SaaS design.

Avoid excessive cards.

Avoid cheap-looking gradients.

Avoid excessive rounded UI.

Avoid template-like AI aesthetics.

The result should look like a real premium creative WordPress theme designed by a professional digital agency.

2. Arabic RTL First

Use Arabic as the primary language.

Use elegant Arabic typography suitable for a premium photography brand.

Do not simply mirror an English layout.

The UI should be intentionally designed for Arabic RTL.

Use proper Arabic spacing, line-height, alignment, and typography.
